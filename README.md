# Aircon

Aplikasi SaaS mobile-first untuk operasional usaha servis AC.

## Pengembangan

- Next.js, TypeScript, Prisma, dan PostgreSQL Supabase.
- Integrasi WhatsApp menggunakan gateway bersama Lumite.
- Perintah yang tersedia ada di `package.json`.
- Dokumentasi fitur dan arsitektur ada di `docs/`.
